# GitHub upload guide

## Repository metadata

- Name: `plant-seedling-classification-cnn`
- Description: `Classifying 12 plant seedling species with TensorFlow/Keras CNNs, comparing a baseline model with an augmented model using batch normalization and adaptive learning rates.`
- Topics: `computer-vision`, `deep-learning`, `tensorflow`, `keras`, `cnn`, `image-classification`, `agriculture`, `plant-seedlings`, `python`.
- Suggested first release: `v0.1.0`, described as an educational research prototype with historical results and revised reusable code.

## Upload using GitHub Desktop (recommended)

1. Extract the ZIP. The project folder contains `README.md`, `src`, `notebooks` and the other repository files.
2. In GitHub Desktop, use **File → New repository**. Set the name above and local path to the parent of the extracted project folder. Do not generate a new README or license over the supplied files. If creating over an existing folder is unavailable, create the repository in a new location and copy the extracted project contents into it, including `.gitignore` and `.github`.
3. Review the changes. No datasets, `.env` files, trained weights, caches or private outputs should be committed.
4. Commit with: `Add plant seedling CNN case study and reproducible project structure`.
5. Publish privately first; verify the README images, notebook rendering and Actions checks. Confirm rights to any course-origin materials using `NOTICE.md`.
6. Run training when you have the data and TensorFlow. Preserve the resulting environment and evaluate the revised implementation. The README already explains that this has not been done during packaging.
7. Set the description/topics, then change visibility to public when ready. Optionally pin the repository on your profile and create the first release.

## Browser upload alternative

Create an empty repository, then use **Add file → Upload files** to upload the extracted CONTENTS, preserving folder structure. Do not upload the ZIP as the project: GitHub will not render the files inside it. Ensure hidden `.gitignore` and `.github/workflows/checks.yml` are included. GitHub's browser limit is 25 MiB per file; all supplied project files are below it.

## Command-line alternative

Create an empty GitHub repository first without an autogenerated README/license. In the extracted project directory:

```bash
git init
git branch -M main
git add .
git diff --cached --stat
git commit -m "Add plant seedling CNN case study and reusable training code"
git remote add origin https://github.com/YOUR_USERNAME/plant-seedling-classification-cnn.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your actual account. Review the staged files before committing. Authenticate through GitHub's supported sign-in flow; do not put tokens in files or remote URLs.
